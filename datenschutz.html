Datenschutz

Transparenz über den Umgang mit Ihren Daten

Status des Projekts (Wichtiger Hinweis)

Der Schutz Ihrer persönlichen Daten ist uns ein besonderes Anliegen. Da sich diese Website in einer Schulprojekt und Entwicklungsphase (Teillieferung) befindet, wird die Erfassung von personenbezogenen Daten auf das absolute technische Minimum reduziert. Bitte beachten Sie, dass der interaktive Bereich (die Eco Simulation) in dieser Version noch nicht implementiert ist. Es werden derzeit keine Benutzerkonten erstellt, keine Highscores auf Servern gespeichert und keine Tracking Cookies von uns gesetzt.

Webhosting über GitHub Pages

Diese Website wird als statische Seite auf GitHub Pages (bereitgestellt von GitHub Inc., 88 Colin P. Kelly Jr. St, San Francisco, CA 94107, USA) gehostet.

Wenn Sie diese Website aufrufen, erfasst GitHub automatisch sogenannte Log Files (Verbindungsdaten). Dazu gehören:

  • Ihre IP Adresse
  • Datum und Uhrzeit des Zugriffs
  • Verwendeter Browsertyp und Betriebssystem
  • Die zuvor besuchte Website (Referrer URL)

Diese Datenverarbeitung ist technisch notwendig, um Ihnen die Website anzuzeigen und die Sicherheit der Server zu gewährleisten (Rechtsgrundlage: Art. 6 Abs. 1 lit. f DSGVO). GitHub kann diese Daten in die USA übertragen. Weitere Informationen finden Sie in der Datenschutzerklärung von GitHub.

Externe Links und Quellen

Die im Recherche Teil verwendeten Quellen und Zitate sind direkt unter den jeweiligen Artikeln transparent verlinkt. Wenn Sie diesen externen Links folgen, verlassen Sie unsere Website. Für die Datenverarbeitung auf den verlinkten Seiten sind ausschließlich deren Betreiber verantwortlich.

Ihre Rechte

Da wir keine Daten wie Namen, E-Mail Adressen oder Profile von Ihnen speichern, können wir diesbezüglich keine Auskünfte erteilen oder Ähnliches veranlassen. Bei allgemeinen Fragen zum Projekt können Sie uns jedoch unter der im Impressum angegebenen E-Mail-Adresse kontaktieren.
