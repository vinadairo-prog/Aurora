El Procesador de Estructuras Dinámicas (XML + XSLT)

Analogía: El XML es el esqueleto puro (datos crudos). El XSL es el plano de diseño (las instrucciones de cómo debe verse). El JavaScript es el artesano que los une y los inyecta en el cuerpo vivo del sitio.

loadXMLXSL() (Transformación en tiempo real)

• async function loadXMLXSL() { ... }
	• Lógica: Es una función asíncrona. Significa que puede pedir datos externamente a través de la red y esperar a que lleguen sin congelar la pantalla del usuario.
• const xmlResponse = await fetch('deepwoods.xml'); ...
	• Lógica: Lanza una petición (fetch) para traer los archivos físicos del servidor. El comando await detiene la ejecución un instante hasta que el archivo se descarga por completo.
• const parser = new DOMParser(); const xmlDoc = parser.parseFromString(...);
	• Lógica: Toma el texto plano de los archivos descargados y lo convierte en estructuras de árbol de datos legibles por el navegador (DOMParser).
• const xsltProcessor = new XSLTProcessor(); xsltProcessor.importStylesheet(xslDoc);
	• Lógica: Activa el motor de transformación nativo del navegador e importa las reglas de diseño del archivo XSL.
• const resultDocument = xsltProcessor.transformToFragment(xmlDoc, document);
	• Lógica: El núcleo del proceso. Fusiona los datos crudos del XML con el diseño del XSL, generando un fragmento de código HTML vivo listo para usarse.
• document.getElementById('xml-target').appendChild(resultDocument);
	• Lógica: Toma ese fragmento HTML recién creado y lo inserta físicamente dentro del contenedor vacío de la página.
